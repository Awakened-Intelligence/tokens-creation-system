# Token Generation & Verification Backend

This backend is a Flask-based API that supports the generation, deployment, verification, and storage of ERC-20 token contracts on Ethereum-compatible networks. It prepares unsigned transactions for contract deployment, compiles and flattens Solidity contracts, verifies deployed contracts via a third-party API (e.g., LineaScan), and saves token details in a database. A custom POA middleware is used to address extraData issues on Proof-of-Authority (POA) networks.

## Features

- **Smart Contract Compilation & Flattening:**  
  Uses Hardhat and `solcx` to compile and flatten Solidity contracts generated by GPT-4.

- **Deployment Preparation:**  
  Prepares unsigned deployment transactions for contract creation without signing—MetaMask is used on the frontend for signing.

- **Contract Verification:**  
  Verifies deployed contracts by comparing compiled bytecode and sending the source code along with constructor arguments to the verification API (e.g., LineaScan).

- **Token Detail Storage:**  
  Saves token details (transaction hash, contract address, token parameters) in a database.

- **Custom POA Middleware:**  
  Handles extraData length errors on POA networks, ensuring compatibility with chains that embed extra data in block headers.

## Project Structure

/backend ├── server.py # Main entry point for the Flask application. ├── .env # Environment variables (e.g., INFURA_URL, LINEASCAN_API_KEY, CHAIN_ID). ├── requirements.txt # List of Python dependencies. ├── routes.py # Flask routes for deployment, verification, and token storage. ├── services/ │ └── blockchain_service.py # Contains logic for compiling, deploying, and verifying contracts. └── middlewares/ └── custom_poa_middleware.py # Custom middleware to patch POA extraData.

## Prerequisites

- **Python 3.8+**  
- **pip** for installing dependencies
- **Hardhat:** Required to flatten contracts. Hardhat should be installed in the `@openzeppelin/contracts` folder (see Hardhat Setup below).  
- A properly configured `.env` file with the following variables:
  - `INFURA_URL`: Your Infura project URL.
  - `LINEASCAN_API_KEY`: API key for the contract verification API.
  - `CHAIN_ID`: The chain ID (e.g., `11155111` for Sepolia).
 ## Hardhat Setup in `@openzeppelin/contracts` Folder

The backend uses Hardhat to flatten Solidity contracts before deployment. To set up Hardhat in the `@openzeppelin/contracts` folder:

1. **Navigate to the Contracts Directory:**
   ```bash
   cd @openzeppelin/contracts
   Initialize a Node.js Project (if not already done):
     -npm init -y
    
   Install Hardhat as a Dev Dependency:
     -npm install --save-dev hardhat
    
   Initialize Hardhat Configuration: Run the following command and follow the prompts:
     -npx hardhat
